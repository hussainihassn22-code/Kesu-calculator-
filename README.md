# 🧮 Advanced Scientific Calculator

A modern, feature-rich calculator application with support for basic arithmetic, scientific calculations, unit conversions, and more!

## ✨ Features

### 📱 Basic Calculator
- ✅ Basic arithmetic operations (+, −, ×, ÷)
- ✅ Decimal number support
- ✅ Percentage calculations
- ✅ Parentheses support
- ✅ Undo/Redo functionality
- ✅ Real-time calculation history

### 🔬 Scientific Calculator
- ✅ Trigonometric functions (sin, cos, tan)
- ✅ Logarithmic functions (log, ln)
- ✅ Power function (x^y)
- ✅ Factorial calculation (n!)
- ✅ Square root (√)

### 🔄 Converters
- **Currency Converter**: USD, EUR, GBP, JPY, PKR
- **Temperature Converter**: Celsius, Fahrenheit, Kelvin
- **Unit Converter**: Meters, Kilometers, Feet, Miles, Kilograms, Pounds

### 💾 Memory Functions
- M+ (Add to memory)
- M− (Subtract from memory)
- MR (Memory Recall)
- MC (Memory Clear)

### 🎨 UI/UX Features
- 🌙 Dark Mode / Light Mode toggle
- 📋 Full calculation history
- 🔄 History modal with past calculations
- 💾 Local storage for history persistence
- 📱 Responsive mobile design
- ⌨️ Full keyboard support

### 🔌 Technical Features
- 📴 Works offline (Progressive Web App)
- 💾 Local storage for settings and history
- ⚡ Fast and lightweight
- 🎯 Tab-based interface
- 🔐 Client-side only (no data sent to servers)

## 🚀 Getting Started

### Using Online
Visit: [GitHub Pages Link] (if deployed)

### Local Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/hussainihassn22-code/Kesu-calculator-.git
   cd Kesu-calculator-
   ```

2. Open `index.html` in your browser

### Install as PWA
1. Open the calculator in your browser
2. Click the install button (usually in the address bar)
3. Or use the menu → "Install app"

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Input numbers |
| `+, −, ×, ÷` | Operations |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last digit |
| `Escape` | Clear display |
| `.` | Decimal point |
